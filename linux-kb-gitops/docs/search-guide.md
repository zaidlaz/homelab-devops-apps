# Quick Search Guide

Use the search bar at the top of the site.

## Search examples

| Search term | Useful for |
|---|---|
| `out of memory` | OOM killer, memory leak, swap usage |
| `high cpu` | Runaway process, load average, CPU saturation |
| `server slow` | CPU, memory, disk I/O, network latency |
| `filesystem full` | Disk full, inode full, deleted files still open |
| `iowait` | Storage latency, SAN/NFS slowness |
| `network unreachable` | Routing, DNS, firewall, interface issue |
