# Linux Operations Knowledge Base

This KB stores Linux production issues, troubleshooting commands, investigation flow, root cause, resolution, and verification steps.

## Common Searches

Try searching for:

- out of memory
- high CPU
- high memory
- server slow
- filesystem full
- load average
- VCS service group
- VMware guest slow

## Main Categories

| Category | Purpose |
|---|---|
| Memory | OOM, swap, high RSS, memory leaks |
| CPU | Runaway processes, high load, Java CPU |
| Filesystem | Disk full, inode full, LVM extension |
| Network | DNS, routing, ports, connectivity |
| Performance | Server slow, IO wait, saturation |
| VCS | Cluster service group troubleshooting |
| VMware | Linux guest issues on virtual infrastructure |
